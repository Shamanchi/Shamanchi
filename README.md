## 🛠 Как я работаю

1. **Анализ задачи** → оцениваю риски, объёмы, защиту, сроки
2. **Архитектура** → закладываю масштабирование сразу, не переписываем потом
3. **Разработка** → AI-ускорение (Codex CLI) + мой контроль качества и безопасности
4. **Инфраструктура** → Docker, CI/CD, мониторинг, логи
5. **Документация** → AGENT.md + README.md + отчёты
6. **Деплой** → готовый к запуску продукт, а не «скрипт на коленке»

**Результат:** вы получаете **продукт** с документацией, который работает под нагрузкой и не падает в 3 ночи.
